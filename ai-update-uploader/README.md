# AI UPDATE Uploader

A private tool operated by the owner of the YouTube channel
"AI UPDATE" (https://www.youtube.com/channel/UClkGkG7TmBMzcpYlzRycXgQ).

It uses the official YouTube Data API v3 solely to upload and manage the
channel owner's own videos (including scheduled publishing), to verify the
owner's own uploads, and to post channel-owner comments on the owner's own
videos. It is not distributed to third parties and does not access any other
person's account or data.
